# 📱 USB Screen Mirror & Laptop Mobile Remote Controller

**USB Screen Mirror Pro** is a high-performance Windows desktop application designed to mirror and fully control your mobile device from your laptop keyboard & mouse over USB cable or Wi-Fi.

## 🌟 Key Features

* **🖱️ Full Laptop Mouse Remote Control**: Click to tap, click & drag to swipe/scroll, right-click for `BACK`, middle-click for `HOME`.
* **⌨️ Direct Laptop Keyboard Typing**: Type text directly from your laptop keyboard into any mobile app (WhatsApp, Messages, Search, Notes).
* **🎮 On-Screen Remote Navigation Bar**: Dedicated buttons for `BACK`, `HOME`, `RECENTS`, `NOTIFICATIONS`, `VOL +`, `VOL -`, `POWER`.
* **📤 Remote Text & URL Injector**: Type any text or URL in the app and click `Send Text` to inject it directly into active mobile input fields.
* **⚡ Zero-Lag 60 FPS HD Mirroring**: Hardware-accelerated H.264 video stream with sub-30ms ultra-low latency.
* **📱 Battery Saver Mode**: Turn off mobile physical screen while keeping laptop mirroring & control active (`-S`).
* **🔊 Audio Forwarding**: Stream mobile audio directly to your laptop speakers.
* **🎥 MP4 Screen Recorder & HD Screenshots**: 1-click video recording and PNG screenshot capture saved to laptop Downloads folder.
* **📶 Cable-Free Wi-Fi Switcher**: Pair over USB once, then switch to wireless remote control wire-free!

## 🎮 How to Control Mobile from Laptop

| Laptop Action | Mobile Response |
| :--- | :--- |
| **Left-Click** | Tap / Select on phone screen |
| **Click & Drag** | Swipe / Scroll (Up, Down, Left, Right) |
| **Right-Click** | **BACK** button |
| **Middle-Click** | **HOME** button |
| **Laptop Keyboard Typing** | Types text directly into active mobile text box |
| **Ctrl + V** | Paste laptop clipboard text into mobile app |
| **Right-Click (when screen dark)** | Turn On Mobile Screen |
| **Alt + O** | Turn off mobile physical screen (keep laptop control active) |
| **Drag & Drop .APK File** | Automatically install app on phone |
| **Drag & Drop Any File** | Transfer file to phone `/sdcard/Download` |

## 🚀 Quick Setup & Usage

1. **Connect Phone via USB Cable**.
2. **Enable USB Debugging** on phone (**Settings** > **Developer Options** > **USB Debugging**).
3. **Open App**: Launch [`UsbScreenMirror.exe`](file:///C:/Users/91810/.gemini/antigravity/scratch/UsbScreenMirror/UsbScreenMirror.exe).
4. Click **`▶ START SCREEN MIRROR & REMOTE CONTROL`**.
